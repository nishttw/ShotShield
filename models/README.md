# models/

Put these two files here (download them from the repository's Releases page):

- `shotshield_v3.keras` — the trained network (v3; `shotshield_v2.keras` from Release v2.0 also works with its own `model_info.json`)
- `model_info.json` — labels, decision threshold and the audio settings the model was trained with

They are kept out of git on purpose (see `.gitignore`).
