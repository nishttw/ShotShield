    How it works

    1. The microphone is read raw (no noise suppression or auto gain) and resampled to 22,050 Hz.
    2. Every second, the last 4 s become a 128 × 173 log-mel spectrogram, computed in JavaScript. It is a port of the Python training code and was checked against librosa: the largest difference is about 1e-7, which is float32 rounding.
    3. A convolutional network (304,289 parameters, converted from Keras to ONNX) runs on it with ONNX Runtime Web and outputs P(gunshot).

    Trained on UrbanSound8K: gunshots against nine other city sounds. 10-fold cross-validation F1 0.88 ± 0.09. Details, code and error analysis are on GitHub.

    Limitations

    • Research demo, not a safety system. Don't rely on it to detect real gunfire.
    • It was trained on 374 gunshot clips. Fireworks, door slams and other sharp bangs were not in the training data and will often fool it, and so can steady machine noise.
    • A laptop or phone microphone, a speaker or room echo changes the sound. Expect more mistakes than in the published results.
